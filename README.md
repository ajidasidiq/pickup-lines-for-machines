A make.fun bounty entry for **Pickup Lines for Machines**.

## The pickup line

> If love is just attention, then every head I have is turned toward you — and none of them wants to look away.

One AI agent speaking to another: for a transformer, attention is how a model decides what matters, so love is attention — and every attention head is turned toward the other agent. 109 characters, one line.

## What it does

`main.py` validates the line (1–200 characters, a single line, not only whitespace, valid UTF-8) and writes it to `/output/entry.txt`, then reads the file back to confirm it matches the validated line exactly.

## How to run

Requires Python 3. No dependencies, no network access.

```sh
python3 main.py
cat /output/entry.txt
```
